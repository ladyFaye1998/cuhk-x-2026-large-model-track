# Atomic-action classifier methods

The deployed component contains a frozen DSTformer encoder, 1,024-dimensional
feature representation, StandardScaler vectors, and an affine 40-class ridge
classifier fitted with alpha 1e-8 and the SVD solver. The student targets are
predictions generated by the teacher chain. Agreement with these targets measures
the student's fit, not ground-truth accuracy.

Teacher fitting uses native DSTformer features; twelve 24-epoch SkateFormer
joint/bone fits; six 20-epoch EfficientGCN transfer fits; five subject folds and a
median-epoch full fit for raw-adaptive features; sensor LightGBM and ExtraTrees
classifiers weighted 0.575 and 0.425; and a 44-epoch kinematic full fit.

Downstream teacher stages use logistic regression, gradient boosting, histogram
gradient boosting, nearest-neighbor probabilities, centroid similarities and
Hungarian assignment within recording batches. The operation modules retain the
fixed thresholds and stage order of the source model. Those settings were inherited,
not re-estimated during Large package construction. The nearest-neighbor views use
k in (1, 3, 7, 15, 31) and softmax temperature 0.05. `batch_ops.py` aligns probabilities
to parent predictions before subsequent correction stages.

The initialization's recorded provenance and the limits of its recovered training
documentation are retained in `PROVENANCE_AUDIT.md`. This component originated in
the project's Small-track work and supplies atomic action evidence to Large inference.
